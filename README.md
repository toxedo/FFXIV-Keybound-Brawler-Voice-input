# FF14 语音输入

按住热键说话，松开自动把词打进游戏输入框。

```
按住 F10 → 说「蒂法」→ 松开 → 游戏里出现「蒂法」并回车
```

## 需要什么

- Windows 10 / 11
- **Python 3.10+**，安装时勾选 `Add python.exe to PATH`
- 麦克风
- 可选：NVIDIA 显卡（有的话快 20 倍，没有也能用）

## 装

1. 双击 **`install.bat`**
   它会检查 Python 并装依赖（sounddevice / faster-whisper / pypinyin），大概 3–5 分钟。

2. 双击 **`run.bat`**
   会弹 UAC，点「是」。**必须给管理员权限**，否则游戏收不到按键。
   首次启动下载模型（small 约 460MB），下完会打印「模型就绪」。

3. 启动后窗口会显示：

   ```
   已选用 F10（记在 hotkey.txt）
   按住 F10 说话，松开自动上屏。Ctrl+C 退出。
   ```

   记住这个键，以后就用它。

## 用

| 操作 | 效果 |
|---|---|
| 按住热键 | 开始录音 |
| 松开 | 识别 → 匹配词表 → 打进游戏 → 回车 |
| `Ctrl+C` | 退出 |

**按热键时游戏要在前台。**

## 换模型

默认 `small`。有显卡的话换更大的明显更准：

```
run.bat --model medium
```

| 模型 | 大小 | CPU 耗时 | GPU 耗时 |
|---|---|---|---|
| small | 460MB | 0.5–1s | 0.05s |
| medium | 1.5GB | 2–3s | 0.1s |

## 热键冲突

如果启动时报「注册失败」，说明这个键被别的程序占了。换一个：

```
run.bat -k F9
run.bat -k Ctrl+Alt+Q
```

想看哪些键可用：

```
python voice_input.py keyscan
```

## 常见问题

**念了半天没反应**
先看窗口有没有打印。没打印 = 热键没触发，换一个键。有打印但游戏里没字 = 没给管理员权限，或者游戏是独占全屏（改成「窗口全屏」）。

**模型下载卡住**
关掉窗口，执行 `setx HF_ENDPOINT https://hf-mirror.com`，重开终端再启动。

**识别不准**
看窗口打印的三行：峰值、识别原文、匹配结果。
- 峰值低于 0.05 → 太小声，调麦克风
- 原文就不对 → 换更大的模型
- 原文对但匹配错 → 把这几个词告诉开发者

**短词（2–3 字）识别差**
这是模型本身的限制。换 `--model medium` 或 `large-v3` 能缓解。

**偶尔卡住好几秒**
识别有 1.5 秒超时，超了会打印 `⏱ ... 放弃这一条` 并跳过。嫌短可以 `--timeout 3`。

## 参数

```
run.bat [--model small|medium|large-v3] [-k 热键] [--no-send] [--device cpu]
```

- `--no-send` 只填字，不自动回车
- `--device cpu` 强制用 CPU
- `--max-sec 15` 单次录音上限
- `--timeout 1.5` 识别超时，超了放弃
- `--interval 0.02` 逐字投递间隔，0=瞬发，调大更像真人打字
- `--short-beam 3` 1 秒以内录音的搜索宽度，调低更快、调高更准

启动时会打印当前配置，可以用来确认参数生效：

```
识别超时 1.5s · 长句 beam 1 · 短词 beam 3 · 投递间隔 0.02s
准备就绪。
```
